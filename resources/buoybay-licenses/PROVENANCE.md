# Provenance

Original implementation for this workspace. Mathematical formulas: expansion
summation using error-free two-sum, Hyndman–Fan type 7 quantiles, centered scaled
moments, ordinary least squares, and the parallel combination of population
moments. No third-party source copied or native library bindings used. Python
math.fsum, statistics, and exact Fraction calculations provide independent test
references. This is a focused Double statistics API, not a conformance claim.
